# stock-erp

Mağaza yönetim panelinin (stok, sipariş, rapor) mobil uygulaması. Müşteriler kendilerine verilen kullanıcı adı ve şifre ile giriş yapar.

**Teknoloji:** Expo SDK 58 · Expo Router · TypeScript · React Query · zustand · react-hook-form + zod · i18next (TR/EN)

## Kurulum

```bash
npm install
npx expo start
```

## Komutlar

```bash
npm run typecheck   # tip kontrolü
npm run lint        # lint
npx expo install <paket>   # paket eklerken her zaman bunu kullanın
```
